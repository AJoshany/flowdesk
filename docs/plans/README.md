# Implementation Plans

This directory contains implementation plans generated from reviewed feature specifications.

Implementation plans are execution documents.

They must:

- Be based on approved specifications.
- Respect architecture decisions.
- Define concrete implementation tasks.
- Map requirements to verification.
- Avoid introducing new product or architecture decisions.

A plan must be reviewed and explicitly approved before implementation begins.

## Lifecycle

Feature Spec
→ Spec Review
→ Implementation Plan
→ Human Approval
→ Implementation
→ Testing
→ Code Review
